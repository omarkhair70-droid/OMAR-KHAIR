# GLOBAL ROOM LAW

Every room must answer seven questions:

1. What is the first memorable still frame?
2. What can the visitor do?
3. What changes because of that action?
4. What settles when action stops?
5. What remains after the room is left?
6. Why could this not be represented better by a normal case study?
7. What is forbidden because it would reduce the room to spectacle?

No room is allowed to survive only through explanatory copy.

# 00 — ENTRANCE

## Thesis

**You are entering a selected world, not opening a résumé.**

The entrance establishes authorship and agency before content.

## First frame

A quiet field.

Visible:
- OMAR KHAIR
- SELECTED WORKS / LIVING EXHIBITION
- INDEX

One unresolved mark / seam / point relationship exists in the field.

It must not already look like any one project.

No thumbnails.
No bio.
No "creative technologist" label.

## Visitor input

Two equal entrance states:

- ENTER WITH SOUND
- ENTER IN SILENCE

Pointer / touch may alter the unresolved mark slightly, but there is no mini-game.

## Event

On entry, the mark separates into two unresolved presences.

This becomes the first material handoff into FIRST CONTACT.

## Residue

Two points / masses with an unresolved relation.

## Transition out

The field gains object weight.
One of the presences becomes OBJECT 001.

## Sound

Silence until the visitor explicitly chooses sound.

If sound is enabled:
- one extremely restrained room-tone wake;
- no musical intro.

## Mobile

The same threshold works one-handed.
No landscape requirement.
The sound choice remains immediate and legible.

## Reduced motion

Static unresolved composition.
Entry is a finite cut / fade.

## Required source assets

None from project repos.

The Entrance belongs to the exhibition itself.

## Forbidden

- portfolio hero;
- showcase reel;
- loading percentage;
- giant 3D sculpture;
- particle tunnel;
- "welcome to my world";
- explanation of the seven works.

# 01 — FIRST CONTACT / OBJECT 001

## Exhibition title

**A SIGNAL CAN EXIST WITHOUT ARRIVING**

## Thesis

**Distance and connection are not the same thing. Meaning changes with angle, reception and agency.**

## First frame

OBJECT 001 sits in a pale chalk / porcelain field.

The object feels physical before it feels digital.

Minimal label:
- OBJECT 001
- TAP / ONLY IF CURIOUS

No neighbour identity.
No named recipient.

## Visitor input

Primary:
- touch / click to wake;
- hold to sustain a signal;
- slight pointer / touch movement changes angle.

No precision puzzle.

## Event

The encounter condenses the original relational arc:

1. object wakes;
2. two forms appear close but unresolved;
3. angle changes interpretation;
4. a signal attempts to cross;
5. one transmission fails / stalls;
6. another reaches;
7. a third form begins in the space between.

The room never claims a relationship has begun.

## Residue

A warm, incomplete seam remains between the two forms.

Not a completed bridge.

## Transition in

Entrance's two unresolved presences gain object/material specificity.

## Transition out

The incomplete seam darkens and rises into space.

It becomes a contour / seam that can belong to a body.

That contour opens SERAPH.

## Sound

If enabled:
- ceramic wake;
- dry room tone;
- restrained signal pulses;
- first harmonic warmth only after something crosses.

No song.
No sentimental score.

## Mobile

This is a mobile-native room.

Touch / hold and haptics matter more than pointer.

Haptic events:
- wake;
- alignment;
- signal arrival.

No haptic spam.

## Reduced motion

Use discrete states:
OBJECT -> GAP -> ANGLE -> SIGNAL -> THIRD THING.

The visitor advances through intent, not auto-motion.

## Required source assets

From FIRST CONTACT:
- OBJECT 001 geometry / physical design language;
- material / colour logic;
- signal / third-thing logic;
- approved sound principles;
- any reusable owned 3D forms that survive generalisation.

A new generalised exhibition-specific version of OBJECT 001 may be authored.

## Context exit

CONTEXT can explain:
- origin as a physical-digital first-contact protocol;
- current source work;
- full original experience / project source.

## Forbidden

- "أنا عمر، جارك";
- recipient names;
- romantic framing;
- surveillance implication;
- dating-app language;
- gamified success score;
- completion to 100%;
- technology demo copy.

# 02 — SERAPH / PRESENCE ROOM

## Exhibition title

**PRESENCE ROOM**

## Thesis

**A digital presence can have inertia, resistance, memory and consequence without becoming a game character.**

## First frame

Darkness is not empty.

A body / relic is partially legible.

The visitor initially reads:
- mass;
- silhouette;
- topology;
- breath / residual movement.

No title card over the body.

No explanatory sentence.

## Visitor input

Depending on the canonical SERAPH state available at implementation time:

Primary candidates:
- stillness;
- pointer / touch proximity;
- approach / distance proxy;
- gaze / orientation only if current canonical source earns and supports it without invasive setup.

No explicit joystick / orbit control.

## Event

The presence notices, but does not mirror.

A compact exhibition event:

1. dormant / barely alive;
2. awareness;
3. one short awakening or state change;
4. response continues after visitor stops;
5. the presence resists perfect control;
6. recovery.

The exhibition cut must not replay the entire SERAPH cinematic experience.

## Residue

One seam / wire / topology fragment remains after the body settles.

The room should end quieter than it began.

## Transition in

FIRST CONTACT's unresolved seam gains depth and becomes bodily topology.

## Transition out

Topology loses machine precision.

The line becomes a mineral crack / retained trace.

Light returns.

FOKHARA begins.

## Sound

When enabled:
- room tone;
- low bodily / mineral energy;
- procedural presence;
- voice only if the current canonical SERAPH voice system remains part of the accepted source work.

Voice must remain sparse.

Sound-off must still feel complete.

## Mobile

Closer camera.
Less geometry / lower wire density if needed.
Same identity.

Touch / stillness replace pointer nuance.

## Reduced motion

One authored still body.
Finite awareness changes.
No continuous camera drift.

## Required source assets

From SERAPH canonical source:
- accepted body / relic GLB;
- current material / topology language;
- current approved audio assets / generation logic where still canonical;
- current THE BODY behaviour if it has progressed beyond the source snapshot.

Implementation must re-check latest canonical source before extraction.

## Context exit

FULL EXPERIENCE should route to SERAPH's full current experience, not to a generic case-study page if the live work is the stronger truth.

## Forbidden

- model viewer;
- drag-to-spin;
- portfolio copy;
- controls tutorial;
- constant motion;
- sci-fi HUD;
- turning SERAPH into the exhibition's global visual skin.

# 03 — FOKHARA / THE FORM REMEMBERS

## Exhibition title

**THE FORM REMEMBERS**

## Thesis

**Material carries previous states. Change does not erase trace.**

## First frame

The room opens bright / mineral after SERAPH.

One real Fokhara object or workshop image holds the pressure point.

Large calm field.
One dominant mass.
One counterweight.

The previous SERAPH seam survives briefly as a mineral / oxide trace.

## Visitor input

Primary:
- scroll / drag / touch moves between two or three material states;
- selected object / image can shift composition slightly;
- a carry gesture may transfer one trace from one state to the next.

No free 3D orbit.

## Event

The room demonstrates retained trace without spectacle:

1. object / material state establishes;
2. composition changes;
3. previous state leaves a small trace;
4. the trace affects the next state;
5. final arrangement settles.

The strongest evidence is real object / workshop material, not simulation.

## Residue

One material-derived colour / mark remains.

It fragments into smaller discrete pieces as the room releases.

## Transition in

SERAPH topology flattens / mineralises into retained material trace.

## Transition out

The retained trace breaks into bead-like units.

Those units land on a tray.

HABBA begins.

## Sound

Mostly quiet.

If enabled:
- real / owned workshop-contact material;
- restrained ceramic scrape / tap;
- kiln / room evidence only if truthful and useful.

No atmospheric "Middle Eastern craft" soundtrack.

## Mobile

Vertical pressure system:
object -> title -> evidence -> trace.

No compressed desktop asymmetry.

## Reduced motion

Use static material states and finite crossfades / cuts.
Trace remains visible as a compositional fact.

## Required source assets

From Fokhara:
- accepted production photography;
- product / studio / workshop evidence;
- material colour sources;
- accepted typographic / layout principles.

Do not resurrect rejected WebGL experiments.

## Context exit

FULL CASE points to the current Fokhara case / live experience.

## Forbidden

- generic pottery aesthetic;
- terracotta cliché;
- fake clay shader;
- reintroducing Material Memory WebGL;
- long product catalogue;
- commerce UI.

# 04 — HABBA / BEAD TABLE

## Exhibition title

**BEAD TABLE**

## Thesis

**Arrangement can be playful, tactile and authored without becoming decorative noise.**

## First frame

A maker's tray / field.

A small number of real Habba bead colours / forms sit with deliberate spacing.

The Fokhara trace has become separate units.

The scene is immediately brighter and lighter than the previous rooms.

## Visitor input

Primary:
- drag / touch beads;
- gather;
- separate;
- connect;
- disturb.

The system can suggest relationships, but must not snap everything into a perfect necklace.

## Event

As the visitor composes:
- proximity creates temporary thread relations;
- colour groups form moods;
- one composition can settle briefly;
- disturbing it is allowed;
- the room remembers one relation after release.

No score.
No "correct" arrangement.

## Residue

One thread arc / spacing rhythm remains after the beads fade.

## Transition in

Fokhara's material trace breaks into discrete physical units.

## Transition out

The distances between the remaining units become temporal intervals.

Thread becomes timing.

The composition bleaches toward porcelain.

WAVEZERO begins.

## Sound

If enabled:
- tiny tactile contact;
- bead / tray punctuation;
- no musical reward loop.

The room can be nearly silent.

## Mobile

Touch is first-class.
Objects must be large enough to manipulate comfortably.
No precision drag requirement.

## Reduced motion

Tap-to-select / tap-to-place arrangement.
No inertial scattering required.

## Required source assets

From Habba:
- real product / bead imagery or extracted colour / shape references;
- brand colours from actual objects;
- bead / thread / tray language.

The room may use abstracted bead geometry derived from real product evidence.

## Context exit

FULL CASE points to Habba's main portfolio case / live storefront.

## Forbidden

- shop grid;
- prices;
- cart;
- cute particle wallpaper;
- pink-everywhere treatment;
- jewelry-luxury language;
- physics sandbox with no compositional intent.

# 05 — WAVEZERO / PORCELAIN LISTENING SURFACE

## Exhibition title

**PORCELAIN LISTENING SURFACE**

## Thesis

**A music interface can feel like a soft physical object rather than a media control panel.**

## First frame

Near-white porcelain field.

One sculpted listening surface.

Minimal state:
- play / stillness;
- one trackless time line / queue trace;
- no album-art wall.

The Habba spacing rhythm survives as intervals.

## Visitor input

Primary:
- press to wake sound;
- drag / move through a short generated / owned sonic sequence;
- queue-like continuation changes the visual surface.

The visitor is not managing a full library.

## Event

The room demonstrates continuity:

1. silent porcelain state;
2. one sound / tone enters;
3. next state is prepared before the current one ends;
4. surface depth / translucency changes;
5. a small queue/history trace remains.

The interaction should feel tactile and calm.

## Residue

One waveform / timing path remains.

## Transition in

Habba's spatial intervals become temporal intervals.

Bead relations become listening rhythm.

## Transition out

Waveform straightens.

Rhythm becomes a measurable signal route.

HILTECH begins.

## Sound

Meaningful when enabled.

Use:
- generated tones;
- original sound design;
- licensed / owned material.

No dependency on commercial songs.

Sound-off:
- surface movement / queue continuity still communicates the piece.

## Mobile

Feels native to touch.
Press / slide interactions should resemble a physical surface more than a desktop scrubber.

## Reduced motion

Static porcelain composition.
Audio state can change without continuous visual motion.

## Required source assets

From WaveZero:
- Porcelain design tokens;
- sculpted surface geometry language;
- selected real UI fragments if they add truth;
- no need to embed Flutter runtime.

New exhibition audio should be authored separately.

## Context exit

FULL CASE points to WaveZero's case study / product source.

## Forbidden

- Spotify clone;
- album-cover carousel;
- visualizer cliché;
- generic waveform wallpaper;
- equalizer UI for decoration;

# 06 — HILTECH / PHYSICAL PATH

## Exhibition title

**PHYSICAL PATH**

## Thesis

**Digital certainty has a physical route.**

## First frame

The WaveZero waveform has become one controlled signal line.

Dark / technical field.

A small part of the path is visible.
The system is not yet complete.

Minimal words:
- BUILD
- ROUTE
- TEST
- PROVE

These are states, not navigation tabs.

## Visitor input

Primary:
- scroll / hold / controlled movement advances one physical path through the four states.

The visitor is not selecting service cards.

## Event

One condensed transformation:

### BUILD
components / endpoints assemble.

### ROUTE
the physical path becomes continuous.

### TEST
the same route becomes measurement / verification.

### PROVE
the route settles into documented certainty.

The same object / path survives all four states.

## Residue

A verified line / node remains.

Certainty is visible but not triumphant.

## Transition in

WaveZero's timing path straightens into signal infrastructure.

## Transition out

The verified line loses its rigid endpoints.

It bends.
Duplicates.
Several arcs appear.

Certainty becomes relation.

The field darkens into NOVA's night.

## Sound

If enabled:
- low machine / route energy;
- short test pulse;
- restrained verification event.

No corporate score.
No sci-fi alarm language.

## Mobile

Four states remain compact.
No long pinned scroll.
The path can recompose vertically.

## Reduced motion

Stepped state transitions:
BUILD -> ROUTE -> TEST -> PROVE.

Each state is a finished still.

## Required source assets

From HILTECH public digital experience:
- accepted infrastructure visual system;
- existing route / fiber / component assets where usable;
- approved real field evidence;
- existing 3D / SVG language only where it supports the condensed piece.

Do not use HILTECH OS.

## Context exit

FULL CASE points to the HILTECH public digital experience case / live site.

## Forbidden

- RFQ flow;
- catalog UI;
- service cards;
- business statistics;
- fake measurement numbers;
- generic neon network;
- HILTECH OS screens.

# BUILD ORDER — NOT VISITOR ORDER

Implementation should not necessarily follow visitor order.

1. Exhibition shell / INDEX / route-state / sound-state / session memory
2. Entrance + Afterimage skeleton
3. FIRST CONTACT — proves threshold / generalized re-authoring

7. WAVEZERO — proves sound-led soft interaction

9. NOVA — proves abstract social / temporal state
10. pairwise transitions
11. full-sequence closure

Reason:
the first four implementation targets prove the exhibition can support radically different mediums before the lighter rooms are polished.
