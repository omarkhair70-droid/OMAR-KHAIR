# OMAR KHAIR — LIVING EXHIBITION / EXPERIENCE ARCHITECTURE

Status: **ARCHITECTURE V1 LOCKED**
Date: 2026-09-23

Parent:
- `docs/OMAR_SELECTED_WORKS_LIVING_EXHIBITION_CURRATION.md`

This document defines the exhibition as one authored work.

It does **not** redesign the existing Omar Khair portfolio.
It does **not** replace the original projects.
It defines the new exhibition that will later become a new project inside Omar's main portfolio.

---

# 0. THESIS

The exhibition is not a website that contains art.

**The exhibition itself is the eighth work.**

Its job is to take seven selected bodies of work and author a new spatial / temporal relationship between them.

The visitor should not leave remembering:
- seven cards;
- seven case studies;
- a tech stack;
- one global visual theme.

The visitor should remember:
- contact;
- presence;
- matter;
- play;
- listening;
- structure;
- collective night;
- residue.

The exhibition is a sequence of encounters with an optional way out at every stage.

---

# 1. PRIMARY EXPERIENCE MODEL

The exhibition is **guided, but never trapped**.

There is one authored default sequence.
There is also a persistent INDEX that allows direct access to every room.

This avoids two bad extremes:

## Not a forced linear film
The visitor is never required to complete a scene, wait for a timer, solve a puzzle or replay an animation to move on.

## Not a project grid
The visitor does not begin by choosing from seven thumbnail cards.

The default path matters because transitions and pacing are part of the work.

The INDEX exists because agency matters too.

### Locked model

```
ENTRANCE
   ↓
FIRST CONTACT
   ↓
SERAPH
   ↓
FOKHARA
   ↓
HABBA
   ↓
WAVEZERO
   ↓
HILTECH
   ↓
NOVA
   ↓
AFTERIMAGE
```

INDEX can jump into any room.

Deep-linking to an individual room is allowed and must still produce an authored arrival.

---

# 2. WHY THIS ORDER

The order is not based on importance, chronology or project size.

It is a material / emotional progression.

## ENTRANCE
No project yet.
The visitor enters Omar's authored field.

## FIRST CONTACT
The exhibition begins by establishing the visitor as a participant.

Question:
**Can a signal exist before meaning is agreed?**

This is the correct threshold because FIRST CONTACT already treats an object / gesture as a door into another state.

## SERAPH
After contact, the visitor meets a presence that appears to notice them.

Question:
**What happens when the digital thing has resistance, memory and stillness?**

This is the first major Monument.

## FOKHARA
After the intensity of SERAPH, the body gives way to material.

Question:
**What can a form retain?**

The exhibition releases into mineral space and physical evidence.

## HABBA
Material becomes arrangement and play.

Question:
**Can composition remain tactile, light and authored without becoming decorative?**

This is an intentional rise in colour and physical play after Fokhara's restraint.

## WAVEZERO
Play settles into listening.

Question:
**What does a soft interface feel like when attention moves from looking to listening?**

The visitor enters a quieter sonic / tactile register.

## HILTECH
Rhythm becomes route, route becomes proof.

Question:
**Can a technical system become an image without pretending not to be technical?**

This is the exhibition's most explicit structural transformation.

## NOVA
Structure opens back into people, time and memory.

Question:
**What does a social system feel like when it is understood as orbit, presence and shared time rather than feed?**

The exhibition ends its project sequence at night, not at certainty.

## AFTERIMAGE
Everything collapses back into residue.

The visitor leaves with a state, not a summary.

# 3. ENTRANCE — NOT A HERO

There is no conventional homepage hero.

No:
- biography paragraph;
- role title;
- services;
- project preview cards;
- availability CTA;
- giant "creative technologist" label.

The entrance is a threshold.

### Required information

Immediately available:
- **OMAR KHAIR**
- **SELECTED WORKS / LIVING EXHIBITION**
- **INDEX**
- a quiet entrance affordance.

The visitor must understand that they may enter, but does not need a tutorial.

### Entrance behaviour

- no fake loading sequence;
- no forced cinematic countdown;
- no autoplay sound;
- no 3D object whose only job is to look expensive.

The entrance should feel like a room before it feels like a homepage.

The first intentional gesture can be used to unlock sound for later rooms.

Sound permission is not framed as a browser chore.
It is simply a choice:

```
ENTER WITH SOUND
ENTER IN SILENCE
```

Both are first-class paths.

The exhibition must remain complete in silence.

# 4. GLOBAL NAVIGATION

Navigation behaves like exhibition orientation, not site chrome.

Persistent minimum:
- OMAR / exhibition mark;
- INDEX;
- SOUND state when relevant;
- CONTEXT only inside a room.

No global:
- Home / Work / About / Contact nav row;
- "hire me";
- social icon strip;
- availability badge.

## INDEX

INDEX is a textual / spatial map of the seven rooms.

It shows:
- room number;
- work name;
- exhibition-cut name;
- visited / current state.

It does **not** show:
- thumbnails;
- project cards;
- stack labels;
- marketing descriptions.

Example:

```
01  FIRST CONTACT     A SIGNAL CAN EXIST WITHOUT ARRIVING
02  SERAPH            PRESENCE ROOM
03  FOKHARA           THE FORM REMEMBERS
04  HABBA             BEAD TABLE
05  WAVEZERO          PORCELAIN LISTENING SURFACE
06  HILTECH           PHYSICAL PATH
07  NOVA              QUIET ORBIT / TONIGHT
```

INDEX can open as:
- full-screen overlay on desktop;
- full-screen sheet on mobile.

Keyboard:
- ESC closes INDEX;
- focus is trapped correctly while open;
- every room remains directly reachable.

# 5. ROOM MODEL

Every room has four layers.

## LAYER A — ARRIVAL
The visitor enters a new material state.

No explanation wall.

## LAYER B — ENCOUNTER
The actual authored interaction / visual / sonic event.

This is the room.

## LAYER C — RESIDUE
The event settles and leaves one trace.

The trace may be:
- a colour;
- alignment;
- a tone;
- a position;
- a transformed object;
- a remembered state.

## LAYER D — CONTEXT
Optional and quiet.

`CONTEXT` reveals a minimal museum-label layer:
- project / work name;
- date or current status where truthful;
- one short paragraph;
- medium;
- link to the complete case / original experience.

The context layer never replaces the encounter.

---

# 6. GLOBAL TRANSITION LAW

Rooms do not dissolve into unrelated pages.

Every transition has three states:

```
RESIDUE
   ↓
SUSPENSION
   ↓
ARRIVAL
```

## RESIDUE
One element from the current room remains after the main scene has settled.

## SUSPENSION
The old world is mostly gone, but the new one has not fully arrived.

This may be:
- darkness;
- paper;
- silence;
- one line;
- one point;
- one held frame.

## ARRIVAL
The retained residue changes material and becomes meaningful inside the next room.

This does **not** mean one literal glowing line must connect every project.

The continuity is conceptual, not a repeated effect.

Examples:
- FIRST CONTACT signal becomes a seam / attention cue entering SERAPH;
- SERAPH's final stillness releases into Fokhara's mineral field;
- Fokhara's retained object trace becomes Habba's arrangement logic;
- Habba's composition settles into WaveZero rhythm;
- WaveZero rhythm becomes HILTECH route timing;
- HILTECH route breaks out of certainty into Nova orbit.

The transition must be authored specifically for the pair of rooms.

No universal wipe animation.

---

# 7. EXHIBITION MEMORY

The exhibition may remember the current session.

It does not identify the visitor.

Session memory can include:
- rooms visited;
- whether sound was enabled;
- whether the visitor stayed still / interacted;
- one or two room-specific state choices;
- order of rooms if INDEX was used.

Use:
- local in-memory state;
- optionally sessionStorage for refresh continuity.

Do not use:
- account;
- fingerprinting;
- covert device data;
- personal profile;
- behavioural scoring.

The session memory exists to author the AFTERIMAGE, not to analyze the person.

No score.
No "you are this type of visitor" output.

---

# 8. AFTERIMAGE

AFTERIMAGE is the final room.

It is not About.
It is not Contact.
It is not a portfolio footer.

The exhibition returns to a sparse field.

The visitor sees transformed traces from the rooms they actually encountered.

Possible residue vocabulary:
- one unresolved signal;
- one body seam / topology fragment;
- one mineral trace;
- one bead / thread relation;
- one soft waveform;
- one measured route;
- one orbit.

These do not appear as seven logos.

They form one final composition.

The composition may vary slightly from session to session based on visit state.

Then the exhibition exposes three quiet exits:

```
INDEX
FULL PORTFOLIO
BEGIN AGAIN
```

Optional:
`ABOUT OMAR` may be accessible from FULL PORTFOLIO rather than turning the final room into biography.

The final emotional state should be:
**something remained.**

# 9. SOUND ARCHITECTURE

There is no global soundtrack.

Silence is the default shared medium.

Sound is room-owned.

## GLOBAL RULES

- no sound before intentional gesture;
- one persistent sound state after consent;
- no room forces sound back on;
- no music bed that runs under all rooms;
- no loud transition stingers as a style system;
- sound must make sense as part of the room.

## ROOM SOUND INTENSITY

### FIRST CONTACT
Meaningful.
Material sound, signal, gap, incomplete resolution.

### SERAPH
Essential when enabled.
Room tone, presence, voice fragments / procedural sound according to current source truth.

### FOKHARA
Mostly quiet.
If sound exists, it should be material / workshop / kiln / contact evidence — never generic ambient music.

### HABBA
Light tactile sound is allowed.
Bead / contact / arrangement sounds can punctuate play.
No cute UI jingle system.

### WAVEZERO
Meaningful.
This room is the most explicit listening-surface study.
Use only owned / generated / licensed audio.

### HILTECH
Restrained.
Signal / route / measurement may be sonified sparingly.
No corporate cinematic soundtrack.

### NOVA
Low nocturnal pulse / social-space atmosphere may exist.
No fake notification chorus.

### AFTERIMAGE
Returns toward silence.

# 10. LIVE VS RE-AUTHORED

The exhibition does not iframe the existing projects.

Each selected work receives a deliberate exhibition cut.

## FIRST CONTACT
**Re-authored live encounter.**
Generalize the current neighbour-specific deployment into a universal relational piece.

## SERAPH
**Live reduced encounter derived from canonical SERAPH systems.**
Use the real body / relic / state / sound language where technically practical.
Do not replicate the full SERAPH site.

## FOKHARA
**New exhibition composition from real Fokhara material / media / accepted visual laws.**
No need to import rejected WebGL experiments.

## HABBA
**New interactive object composition.**
Derived from real bead / thread / tray principles.
Not the shop runtime.

## WAVEZERO
**New listening surface derived from the Porcelain design language and real product states.**
Not the full Flutter app embedded in browser.

## HILTECH
**New condensed visual-system cut.**
Derived from the existing public digital experience, especially BUILD -> ROUTE -> TEST -> PROVE.
Not the public corporate site embedded or copied route-for-route.

## NOVA
**New abstract social-time state.**
Derived from Quiet Orbit / Tonight / Memories laws.
No private or fake user feed.

# 11. SOURCE / PROVENANCE LAW

The new exhibition must have its own repository.

The existing portfolio repo remains untouched as the primary portfolio source after research is transferred.

Each room in the new repository gets a source ledger recording:
- canonical source repository;
- source commit SHA used;
- exported / copied media;
- any re-authored code derived from owned source;
- audio provenance;
- 3D asset provenance;
- generated asset provenance where relevant.

The exhibition must not rely on unstable cross-repository runtime imports.

Source projects remain canonical for their own product truth.

The exhibition repository owns only the exhibition cut.

---

# 12. TECHNICAL ARCHITECTURE — PRINCIPLE

Do not choose one renderer for ideological consistency.

Choose the medium that serves each room.

Shared shell:
- Next.js;
- React;
- TypeScript;
- GSAP / ScrollTrigger where useful;
- Web Audio shared bus;
- scene / room state;
- accessible navigation;
- session memory.

Room-specific tools may include:
- Three.js / React Three Fiber;
- GLSL / custom shaders when meaning requires them;
- PixiJS / Canvas;
- DOM / CSS;
- SVG;
- video;
- Web Audio;
- Blender-authored assets;
- procedural geometry;
- haptics on supported mobile devices.

No technology is admitted because the exhibition is supposed to look technical.

A room may be technically simple and still be the strongest room.

---

# 13. RENDERER / PERFORMANCE MODEL

Do **not** run seven heavy worlds simultaneously.

Rooms are lazy-loaded.

At any moment:
- current room is fully active;
- next room may preload its critical assets;
- previous room keeps only the residue required for transition;
- heavy renderers are suspended / disposed when no longer needed.

For 3D:
- capped DPR;
- mobile geometry / shader budget;
- texture compression where useful;
- no invisible full-scene rendering in background rooms.

For media:
- explicit preload policy;
- responsive sources;
- avoid decoding multiple large videos at once.

The exhibition must feel heavy artistically, not computationally careless.

---

# 14. URL / DEEP-LINK MODEL

Every room must be addressable.

Working route model:

```
/                    Entrance
/first-contact
/seraph
/fokhara
/habba
/wavezero
/hiltech
/nova
/afterimage
```

Navigation between rooms should feel continuous even though routes are addressable.

A deep-link arrival must:
- skip the global entrance if appropriate;
- perform that room's own authored arrival;
- retain INDEX and context access.

No room requires the visitor to have seen the previous room for basic comprehension.

The default sequence gains meaning from continuity, but direct access remains valid.

---

# 15. DESKTOP EXPERIENCE

Desktop can use:
- spatial camera movement;
- larger negative space;
- side-to-side composition;
- pointer proximity;
- stillness;
- layered sound position;
- larger scene transitions.

But desktop must not become:
- mouse-chasing;
- 3D orbit controls;
- scroll-jacking;
- game navigation.

Scroll, pointer, click / hold and stillness are inputs, not the subject.

---

# 16. MOBILE EXPERIENCE

Mobile is not a reduced fallback.

It is the same exhibition authored for a hand-held body.

Use:
- vertical depth;
- touch / hold;
- scroll velocity;
- device-safe haptics;
- shorter camera travel;
- fewer simultaneous objects;
- closer material detail;
- stronger sequencing.

Do not require:
- hover;
- precision pointer;
- landscape;
- motion sensor permission;
- camera permission.

A room may choose a different composition on mobile while preserving the same thesis.

FIRST CONTACT is especially important as a mobile-native threshold because its source work already begins from a physical object into a phone encounter.

---

# 17. REDUCED MOTION

Reduced motion is an authored edition of the exhibition.

Not a broken version.

Each room must define:
- one memorable still state;
- finite fades / cuts;
- static spatial hierarchy;
- alternate interaction if the main interaction depends on continuous motion.

Examples:
- SERAPH: still presence + finite state changes;
- FOKHARA: image / object recomposition through cuts rather than travel;
- FIRST CONTACT: discrete state changes;
- HABBA: tap-based arrangement;
- WAVEZERO: static listening surface + intentional play state;
- HILTECH: stepped BUILD / ROUTE / TEST / PROVE states;
- NOVA: fixed orbit states / fades.

No information or room exit may depend on motion.

---

# 18. ACCESSIBILITY / AGENCY

Every room must preserve:
- keyboard exit;
- INDEX access;
- visible focus where controls exist;
- readable context layer;
- sound off path;
- reduced-motion path;
- no interaction trap.

Voice / important sound content:
- captions / transcript available through CONTEXT or a quiet caption control;
- not forced over the composition unless required for understanding.

No room should punish:
- skipping;
- silence;
- declining sound;
- choosing INDEX;
- leaving early.

Agency is part of the art direction.

---

# 19. CONTEXT / FULL CASE RELATION

The exhibition never becomes the explanatory portfolio.

Each room's CONTEXT layer can include one route:

`FULL CASE ↗`

Target:
- the existing main Omar portfolio case study where one exists;
- the original full experience where that is the better truth;
- canonical repo only when no public case / experience exists.

The link opens without pretending the exhibition is the complete product explanation.

Suggested label structure:

```
WORK
FOKHARA

EXHIBITION CUT
THE FORM REMEMBERS

SOURCE
Experimental redesign / material-led commerce

FULL CASE ↗
```

Keep it short.

---

# 20. GLOBAL VISUAL IDENTITY

The exhibition does not impose one palette or one 3D material across all rooms.

Global identity comes from:
- Omar mark / typography system;
- INDEX;
- spacing / calibration;
- transition discipline;
- context-label system;
- treatment of silence;
- finite motion;
- how rooms settle;
- how residue is carried.

The shell should be quiet enough that each room can own its world.

Do not make every room:
- black;
- mineral;
- wireframe;
- orange;
- serif;
- cinematic in the same way.

The exhibition is unified by authorship, not skin.

---

# 21. VISITOR TIME

There is no required total duration.

A visitor can:
- pass through quickly in 3–5 minutes;
- spend much longer inside one room;
- jump directly through INDEX;
- leave after one work.

Each room should reveal its core idea within roughly the first 10–20 seconds of attention.

Deeper interaction is optional.

No room hides all meaning behind a long scroll or a 60-second unskippable sequence.

---

# 22. EXHIBITION CLOSURE STANDARD

The exhibition is not complete when all routes render.

It closes only when:

- the full default sequence has a perceivable arc;
- every room can stand as a still frame;
- every room has a reason to exist distinct from the source case study;
- transitions feel authored pair-by-pair;
- INDEX never feels like a portfolio grid;
- sound-on and sound-off are both complete;
- mobile is authored;
- reduced motion is authored;
- deep links are valid;
- full-case exits are truthful;
- source provenance is complete;
- no room is a stack showcase;
- no room is merely a reskin of the source project;
- AFTERIMAGE feels like a conclusion to the exhibition rather than a footer.
