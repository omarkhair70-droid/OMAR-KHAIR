# OMAR KHAIR — SELECTED WORKS / LIVING EXHIBITION

Status: **CURATION V1 LOCKED FOR EXPERIENCE AUTHORSHIP**
Date: 2026-09-23

This document supersedes the idea of redesigning the existing Omar Khair portfolio into an art portfolio.

The existing portfolio remains the complete explanatory source:
- full project range;
- case studies;
- product / engineering context;
- roles;
- evidence;
- links;
- delivery history.

The new work is a separate authored exhibition.

It is not:
- Portfolio V2;
- a prettier version of the current portfolio;
- a recruiter site;
- a complete archive;
- a list of every repo;
- a fine-art-only website.

It is itself a new work by Omar.

The exhibition selects a very small body of existing work and transforms each selected work into a new encounter.

The current portfolio explains the work.

The exhibition lets the visitor experience a concentrated authored state of the work.

---

## 1. CURATORIAL LAW

A project is admitted only if it can become an encounter with a distinct sensory / spatial / behavioural reason to exist.

Repository size, technical difficulty, commercial value and personal nostalgia are not admission criteria.

A project may be excellent and still remain outside this exhibition.

Admission test:

1. Does the work contain a real part of Omar's visual / spatial / sonic / behavioural imagination?
2. Can that part survive after feature lists and stack explanations are removed?
3. Can it become a distinct room / encounter without faking artistic meaning?
4. Does it add a material, rhythm or state not already carried better by another selected work?
5. Can the exhibition cut remain truthful to the actual source work?

If not, it stays in the main portfolio.

## 2. LOCKED V1 BODY — SEVEN WORKS

### 01 — SERAPH
**Role:** Flagship living presence  
**Weight:** Monument / encounter

Source truth:
- embodied interactive world;
- body, digital presence, material state, sound, memory and space;
- interaction through stillness, approach, openness, asymmetry and rhythm;
- current canonical experiences include THE BODY and WAKING RELIC.

Exhibition cut:
**PRESENCE ROOM**

The visitor does not receive a SERAPH case study.
They enter a reduced encounter with one presence.

Key materials:
- body / relic;
- gaze or orientation where the current source earns it;
- scarce movement;
- sound as architecture;
- delayed response;
- memory;
- stillness.

The exhibition may route to the full SERAPH experience after the encounter.

Do not:
- explain Three.js;
- present controls;
- use a model viewer;
- duplicate every SERAPH chapter;
- make the exhibition globally inherit SERAPH's darkness.

---

### 02 — FOKHARA
**Role:** Material memory  
**Weight:** Monument / material work

Source truth:
- THE FORM REMEMBERS;
- calm mineral field / active internal pressure;
- becoming, retained trace and centered tension;
- color as a material event;
- accepted production direction explicitly rejected shader-led WebGL and larger 3D theatre when they read as technology instead of meaning.

Exhibition cut:
**THE FORM REMEMBERS**

This is not a screenshot gallery of the storefront.

The room uses:
- real object / workshop evidence;
- mineral field;
- scale;
- pressure and release;
- retained visual trace;
- object carry / recomposition only where it preserves meaning.

Technology must disappear behind material logic.

Do not add WebGL merely because the exhibition can.

---

### 03 — FIRST CONTACT
**Role:** Relational object / encounter protocol  
**Weight:** Monument / encounter

Source truth:
- physical-digital first-contact protocol;
- OBJECT 001;
- NFC / QR threshold;
- safe strangeness -> curiosity -> reinterpretation -> signal -> shared life -> agency;
- sound and haptics behave as material;
- recipient agency is part of the work.

The current deployment-specific copy about Omar being the recipient's neighbour is not the exhibition piece.

Exhibition cut:
**OBJECT 001 / A SIGNAL CAN EXIST WITHOUT ARRIVING**

Generalize the work away from one named recipient.

Preserve:
- object threshold;
- two unresolved nodes;
- angle / reinterpretation;
- signal;
- third thing;
- voluntary agency;
- incomplete ending.

Remove:
- neighbour-specific biography;
- recipient-specific name;
- any implication that the exhibition visitor is the original recipient.

The work becomes a reusable statement about distance, signal, interpretation and the space between people.

### 04 — WAVEZERO
**Role:** Listening object / soft interface  
**Weight:** Major work / sonic-design encounter

Source truth:
- real Android-first local / offline music product;
- deliberate Porcelain design language;
- milk-white surfaces;
- restrained translucency;
- soft depth;
- small tactile movement;
- calm daily-use identity.

Exhibition cut:
**PORCELAIN LISTENING SURFACE**

Do not reproduce the whole player.

Extract:
- porcelain surface;
- listening state;
- queue / continuity as rhythm;
- tactile micro-movement;
- silence / sound transition;
- one or two real product surfaces as evidence.

The exhibition cut should feel like a listening instrument derived from WaveZero's interface language.

No third-party song is required.
Sound used by the exhibition must be owned, generated, licensed or otherwise safe to present.

---

### 05 — HILTECH — PUBLIC DIGITAL EXPERIENCE
**Role:** Infrastructure made visible  
**Weight:** Monument / system-image work

Only the public HILTECH digital experience enters.

HILTECH OS / the unfinished internal company operating system does **not** enter V1.

Source truth:
- infrastructure company x technical commerce;
- BUILD -> ROUTE -> TEST -> PROVE;
- CHAOS -> STRUCTURE -> FLOW -> VERIFICATION -> CERTAINTY;
- core visual idea: make invisible infrastructure visible, then demonstrate its certainty;
- existing public experience already uses authored motion / route / infrastructure grammar.

Exhibition cut:
**PHYSICAL PATH**

Strip away commerce, RFQ explanation and broad corporate navigation.

Keep one concentrated transformation:
**BUILD -> ROUTE -> TEST -> PROVE**

Potential materials:
- fiber / route / termination;
- signal;
- scale change;
- measurement;
- evidence;
- certainty / settle.

This is the exhibition's strongest proof that a technical system can become authored visual language without pretending to be fine art.

---

### 06 — HABBA
**Role:** Play / arrangement / handmade colour  
**Weight:** Major study / bright counter-room

Source truth:
- handmade bead-accessories storefront;
- "a handmade bead playground you can shop";
- bead, thread and tray are already defined as interface primitives;
- mood color rather than generic pink;
- guided discovery behaves like composing a set.

Exhibition cut:
**BEAD TABLE**

This room exists because the exhibition needs a lighter, tactile, playful register.

The visitor should be able to:
- gather;
- separate;
- connect;
- compose;
- disturb;
- leave an arrangement.

The piece should derive from real Habba object colours and handmade logic.

It must not become:
- a shop;
- a product grid;
- a luxury-jewelry parody;
- meaningless particle dots.

---

### 07 — NOVA
**Role:** Social time / orbit / memory  
**Weight:** Major study / nocturnal counter-state

Source truth:
- Quiet Orbit visual identity;
- approach -> orbit -> settle motion grammar;
- Pulse -> Orbit -> Tonight -> Rooms -> Memories;
- orbit motif is semantic: relationship, presence, selection and progress;
- Tonight is intentionally alive, intimate and nocturnal;
- Memories are the warm counterweight to live surfaces.

Exhibition cut:
**QUIET ORBIT / TONIGHT**

Do not present Nova as a social-app case study.

Use an abstract, non-personal state:
- orbit;
- proximity;
- pulse;
- time;
- memory;
- settle.

No real user data.
No fake social activity.
No feed reproduction unless one very small real UI fragment is needed as evidence.

This gives the exhibition a social / temporal state different from FIRST CONTACT's one-to-one encounter.

## 3. RESERVE — NOT V1

### TESWA

Teswa is not rejected as a work.

It is held outside V1 because its strongest exhibition idea currently overlaps other selected encounters:
- object / value movement between people;
- offer / handoff;
- chat / exchange;
- local human connection.

FIRST CONTACT currently carries relational signal more purely.
NOVA currently carries social state / time more distinctly.
FOKHARA / HABBA already carry object/material registers.

Teswa may enter a later edition when one specific current behaviour — such as BETWEEN US / negotiation / moving value — produces a piece that adds a new state rather than repeating the current seven.

The full product remains important in the main portfolio.

## 5. EXHIBITION RELATION TO THE MAIN PORTFOLIO

The exhibition never carries the burden of full explanation.

Each encounter may expose one quiet exit:

**CONTEXT / FULL CASE**

That route points to the existing Omar portfolio or the canonical full project experience.

The visitor can choose:

**experience first**
or
**understand more**

The exhibition itself will later be added to the main portfolio as a new authored project.

Therefore the system is recursive:

original work
-> exhibition cut
-> living exhibition
-> living exhibition becomes a new work in Omar's main portfolio

---

## 6. V1 MATERIAL RANGE

The seven works deliberately create seven different material states:

1. SERAPH — body / presence / sound / memory
2. FOKHARA — mineral / object / trace / pressure
3. FIRST CONTACT — distance / object / signal / agency
4. WAVEZERO — listening / porcelain / continuity / softness
5. HILTECH — route / infrastructure / verification / certainty
6. HABBA — bead / thread / colour / composition / play
7. NOVA — orbit / night / pulse / social memory

This diversity is a feature.

The exhibition should not force all seven into one visual skin.

Authorship comes from:
- pacing;
- thresholds;
- restraint;
- relation between visitor and work;
- recurring respect for stillness;
- finite motion;
- precise transitions;
- selective explanation.
