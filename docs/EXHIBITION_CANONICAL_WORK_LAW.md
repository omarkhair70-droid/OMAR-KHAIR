# EXHIBITION CANONICAL WORK LAW

Status: **LOCKED**
Date: 2026-09-23

This corrects an important interpretation of "exhibition cut."

The exhibition is the new artwork.

The selected source projects are **not rebuilt as new projects** inside it.

## Core law

```
CANONICAL WORK
   ↓
CURATED REAL FRAGMENT
   ↓
EXHIBITION FRAMING / TRANSITION / PACING
```

Not:

```
CANONICAL WORK
   ↓
REMAKE THE PROJECT
   ↓
PUT THE REMAKE IN THE EXHIBITION
```

For web-native works, prefer exact owned source components / scenes / media from a recorded commit and adapt only what is required for:
- isolation;
- exhibition routing;
- responsive composition;
- performance;
- accessibility;
- transition in / out.

For native/mobile works, show real product states, captures, motion, owned assets or a minimal browser presentation of those real states. Do not rebuild the product as a browser clone.

For photographic / material works, use real source media and authored exhibition framing. Do not generate fake evidence.

## What is new

The exhibition owns:
- entrance;
- INDEX;
- spatial / temporal sequencing;
- pairwise transitions;
- global sound law;
- room framing;
- selection;
- context labels;
- session residue;
- AFTERIMAGE.

These are enough to make the exhibition a new work.

## FIRST CONTACT exception

FIRST CONTACT is already a short encounter and the existing exhibition implementation is accepted.

Its generalized room adaptation may remain because it preserves the source interaction grammar and removes one recipient-specific deployment.

This exception does **not** create a precedent for rebuilding:
- SERAPH;
- Fokhara;
- Habba;
- WaveZero;
- HILTECH;
- Nova.

For those works, source-first reuse is the default.

## Source truth

Before implementing any room after FIRST CONTACT:
1. re-check the current canonical source repo;
2. record the exact source commit;
3. identify the smallest real fragment that carries the work;
4. extract / adapt that fragment;
5. add only exhibition-owned framing and transition material.

If a room starts becoming a second version of the source project, stop.
