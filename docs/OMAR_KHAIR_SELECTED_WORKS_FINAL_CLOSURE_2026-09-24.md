# 3. INTERNAL CURATORIAL SPINE

**The room sees you → you attempt contact → contact takes a body → the body disappears → you carry its trace.**

This is an internal thesis used to test the exhibition's coherence.

It is not a decoding key that must be shown to the visitor.

The work should remain capable of producing interpretations beyond this sentence.

# 4. FINAL JURY DECISION

## WALL OF EYES — KEEP / CLOSED

Role:
- threshold;
- witness field;
- reversal of the normal viewer/work relationship;
- exhibition-born work rather than imported project material.

Accepted qualities:
- visually dense but informationally spare;
- procedural eyes, broadcast frames and signal interruptions;
- sound / silence choice;
- the visitor is noticed before the first selected source work begins.

Do not make it visually quieter merely to imitate gallery minimalism.

Its discipline comes from carrying one idea strongly, not from visual emptiness.

## FIRST CONTACT — KEEP / CLOSED UNLESS A CONCRETE PROBLEM APPEARS

Role:
- the visitor moves from being watched to attempting relation;
- object, distance, angle, signal and the third thing establish contact as an uncertain event.

The current language is accepted as part of the work rather than treated automatically as explanatory UI.

Do not reduce text simply to make the room appear more cryptic or “more fine art.”

Future subtraction is justified only if a specific line is proven to repeat or weaken an event already carried better by the work.

## SERAPH / THE BODY — KEEP / CLOSED

Role:
- contact becomes embodied presence;
- body, perception, stillness, response, sound and memory become the central encounter.

The exhibition uses a pinned canonical SERAPH fragment rather than rebuilding the source project.

The body remains the primary event.

No new spectacle, model-viewer controls, decorative particles or explanatory layer is required.

## AFTERIMAGE / ABSENCE — KEEP / CLOSED

Role:
- presence collapses into absence;
- the final trace is produced from the same canonical SERAPH body;
- the encounter's final state influences remembered posture, attention, recognition, residue and afterimage strength;
- the remembered body loses material presence and disappears;
- the room settles before exhibition identity and minimal exit controls return.

This is not a generic body symbol.

It is a remembered state of the body that was encountered.

Do not add a fourth project after it.
Do not add a closing soundtrack by default.
Do not label the experience “AFTERIMAGE” for the visitor unless a later concrete reason requires it.

# 5. MEDIUM JUSTIFICATION

The browser is not a container for documentation here.

It is part of the artwork because the work depends on:
- pointer / touch presence;
- gaze-like response;
- optional sound;
- haptics where supported;
- real-time 3D presence;
- perception / attention;
- session memory;
- authored temporal transitions;
- the remembered body changing according to the encounter.

The technical system is justified only where it becomes material or behaviour.

No technology is admitted simply because it is available.

---

# 6. FINAL FORM / CONTENT TEST

The final sequence passes the exhibition's core test:

- the opening watches;
- FIRST CONTACT asks the visitor to act;
- SERAPH turns relation into embodied presence;
- the final room uses the actual remembered body rather than an abstract stand-in;
- disappearance becomes the final event rather than a transition to more content.

The exhibition therefore ends because the work has reached its conclusion, not because the project list has run out.

---

# 7. TEXT / INTERPRETATION LAW

The exhibition does not require obscurity in order to count as art.

A sentence may remain when it:
- is part of the work's rhythm;
- opens meaning rather than merely decoding mechanics;
- carries a poetic or conceptual function beyond interface instruction.

Likewise, silence and ambiguity are not automatically superior.

The criterion is whether a choice belongs to the work.

No future edit should be justified only by:
- “fine art should be mysterious”;
- “fine art should be minimal”;
- “a portfolio needs more breadth”;
- “the technology can do more.”

---

# 8. STOP RULE

Creative expansion is now closed.

A new change is admitted only when at least one of these is true:
1. a real visual or interaction problem is observed;
2. the current behaviour contradicts the artistic thesis;
3. accessibility, mobile, reduced-motion or performance breaks the encounter;
4. provenance or source truth is inaccurate;
5. a jury-level review identifies a concrete weakness in form, pacing, sound or presentation.

Otherwise, leave the work alone.
